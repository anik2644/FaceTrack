# FaceTrack

FaceTrack is a real-time face tracking application that utilizes computer vision and deep learning techniques to accurately identify and track faces across various environments. This project aims to provide a robust solution for face detection and tracking, applicable in various fields such as security, user interaction, and augmented reality.

## Features
- Real-time face tracking
- Multi-face detection
- Python-based implementation
- Easy-to-use interface
- Support for various input sources (camera, video files)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/anik2644/FaceTrack.git
   cd FaceTrack
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the face tracking application using:
```bash
python main.py
```
You can modify the input source in the `main.py` file to use either a webcam or a video file.
